## 大模型基础

### [[LLM|L-L-M|大型语言模型]] 工作原理

大型语言模型（Large Language Model）是基于 [[Transformer|传思佛摸|深度学习架构]] 架构的神经网络模型，通过在海量文本数据上进行预训练，学习语言的统计规律和语义表示。

**核心概念**

- **Token**：文本的最小处理单元（中文约1.5字/token，英文约0.75词/token）
- **Context Length**：模型能处理的最大上下文长度（如 4K、32K、128K）
- **Temperature**：控制输出随机性的参数（0-2，越小越确定）
- **Top-p**：核采样参数，控制候选词范围

## RAG 检索增强生成

### 什么是 [[RAG|拉格|检索增强生成]]？

RAG（Retrieval-Augmented Generation）是一种结合外部知识库的大模型问答技术，解决大模型"幻觉"和知识更新问题。

{RAGFlow}

### RAG 工作流程详解

1. **文档处理**：PDF/Word → 切片（500-1000字）
2. **向量化**：使用 BGE-M3 生成 1024 维向量
3. **存储**：向量存入 Milvus 数据库
4. **检索**：用户问题 → 向量化 → 相似度检索 → Top-K
5. **重排序**：gte-Qwen2-7B 精排
6. **生成**：拼接上下文 + Prompt → 大模型生成答案

### 向量检索算法

**[[HNSW|H-N-S-W|分层导航小世界图]]**（Hierarchical Navigable Small World）

- 多层图结构
- 快速近似最近邻搜索
- 查询时间复杂度：O(log N)

**余弦相似度**

计算两个向量的夹角余弦值：

```
cos(θ) = (A·B) / (|A|×|B|)
```

范围 [-1, 1]，值越大越相似。

## vLLM 推理优化

### [[vLLM|v-艾偶-艾偶-艾姆|高性能大模型推理引擎]]

vLLM 是加州大学伯克利分校开发的高性能大模型推理框架。

**核心技术**

1. **PagedAttention**：将 KV Cache 分页管理，显存利用率提升数倍
2. **Continuous Batching**：动态批处理，来一个处理一个
3. **并行解码**：支持张量并行、流水线并行

**性能提升**

- 吞吐量：原生 PyTorch 的 3-4 倍
- 显存占用：减少 50%+
- 首字延迟：< 500ms

## 模型量化

### [[INT8|印特8|8位整数量化]] 量化

将 FP16（16位浮点）模型参数转换为 INT8（8位整数），降低显存占用和加速推理。

**效果**

- 显存减半
- 推理速度提升 1.5-2 倍
- 精度损失 < 2%

## Text2SQL

### 什么是 [[Text2SQL|特克斯特兔思Q偶|自然语言转SQL]]？

将用户的自然语言问题自动转换为 SQL 查询语句。

### 实现方案

1. **Schema 向量化**：将数据库表结构转为向量
2. **Few-shot 示例**：提供 5-10 个示例 SQL
3. **Chain-of-Thought**：引导模型逐步推理
4. **SQL 校验**：语法检查 + 安全审核

### 准确率提升技巧

- 详细的表和列注释
- 提供业务术语映射
- 历史查询样例库
- 多轮对话澄清需求

## Prompt 工程

### 什么是 [[Prompt|撇破母特|提示词]]？

Prompt 是给大模型的输入指令，决定模型的输出质量。

### 优秀 Prompt 的特征

1. **清晰具体**：明确任务目标
2. **提供上下文**：背景信息
3. **给出示例**：Few-shot
4. **设定角色**：你是XX专家
5. **输出格式**：JSON/Markdown

### Few-shot 示例

```
# Zero-shot（无示例）
问：Flink 怎么部署？

# Few-shot（有示例）
示例1：
问：Spark 怎么部署？
答：【详细步骤】

示例2：
问：Kafka 怎么部署？
答：【详细步骤】

现在回答：
问：Flink 怎么部署？
```

## 面试常见问题

### Q1：RAG 和 微调（Fine-tuning）有什么区别？

**RAG**
- 无需训练模型
- 知识可实时更新
- 适合企业内部文档

**Fine-tuning**
- 需要训练数据和算力
- 知识固化在模型中
- 适合特定领域任务

### Q2：如何评估 RAG 效果？

- **召回率**：相关文档是否被检索到
- **准确率**：答案是否正确
- **延迟**：检索 + 生成的总时间
- **用户满意度**：人工评估

### Q3：大模型如何防止幻觉？

1. RAG 基于真实文档回答
2. 引用来源，可追溯验证
3. Prompt 强调"不知道就说不知道"
4. 温度参数设置较低（0.1-0.3）
