## 项目一：SuperAgent 智能体平台

### 项目背景

面向军工企业内网环境的通用智能体平台，基于 Google Agent2Agent Protocol (A2A) 协议，用户通过自然语言对话提出需求，决策智能体拆解任务并调度专业智能体协作完成。

### 技术架构

```
┌─────────────────────────────────────┐
│  前端：Vue3 + WebSocket + SSE       │
├─────────────────────────────────────┤
│  网关：Spring Cloud Gateway          │
├─────────────────────────────────────┤
│  服务层                               │
│  ├─ 决策智能体（任务拆解）            │
│  ├─ PPT 智能体                       │
│  ├─ 文档智能体                       │
│  └─ 代码智能体                       │
├─────────────────────────────────────┤
│  推理层：vLLM + Triton               │
│  ├─ Qwen3-14B（对话）                │
│  ├─ Qwen3-Coder-7B（代码）           │
│  └─ DeepSeek-V3（推理）              │
├─────────────────────────────────────┤
│  基础设施：K8s + Docker              │
└─────────────────────────────────────┘
```

### 核心功能

1. **任务拆解与编排**
   - 用户意图识别
   - 子任务生成
   - 智能体调度

2. **多智能体协作**
   - A2A 协议通信
   - 状态同步
   - 结果聚合

3. **任务执行监控**
   - 实时日志流（SSE）
   - 任务状态追踪
   - 异常告警

### 技术亮点

- **容器隔离**：每个任务独立 Docker 容器
- **资源调度**：K8s 动态分配资源
- **断点续传**：任务失败可恢复
- **实时反馈**：WebSocket 推送进度

### 我的职责

1. 设计多智能体协作框架
2. 实现任务调度与编排系统
3. 开发实时日志流（SSE + WebSocket）
4. 容器化部署与 K8s 编排

## 项目二：企业智能问答平台

### 项目背景

为军工企业内网环境开发的 AI 驱动的智能问答与数据分析平台，基于 RAG 技术实现企业知识库问答、自然语言数据查询、智能报表生成。

### 技术架构

```
用户提问
    ↓
Query 改写（提升检索效果）
    ↓
向量检索（BGE-M3 + Milvus）
    ↓ Top 20
BM25 关键词检索
    ↓ Top 20
合并去重（30-40 个候选）
    ↓
重排序（gte-Qwen2-7B）
    ↓ Top 3-5
拼接 Prompt
    ↓
大模型生成（Qwen3-14B）
    ↓
答案 + 来源
```

### 核心功能

1. **文档问答**
   - PDF/Word/PPT 解析
   - 智能切片（500-1000字）
   - 向量化存储

2. **Text2SQL**
   - Schema 向量化
   - Few-shot 示例
   - SQL 安全审核

3. **数据分析**
   - 自然语言生成图表
   - 趋势分析
   - 异常检测

### 性能指标

- 检索延迟：< 50ms
- 召回率：95%+
- SQL 准确率：90%+
- 支持百万级文档

### 技术难点与解决方案

**难点 1：检索准确率低**

解决方案：
- 混合检索（向量 + BM25）
- 二阶段重排序
- Query 改写

**难点 2：SQL 生成错误**

解决方案：
- Schema 详细注释
- Few-shot 示例库
- 语法校验 + 安全审核
- 多轮对话澄清

**难点 3：首字延迟高**

解决方案：
- vLLM 推理优化
- PagedAttention
- INT8 量化
- Continuous Batching

## 项目三：实时数据湖平台

### 项目背景

基于 Flink + Hudi 构建的实时数据湖平台，支持 CDC 数据同步、实时数据入湖、流批一体查询。

### 技术架构

```
数据源（Oracle/MySQL）
    ↓ Flink CDC
Kafka（数据分发）
    ↓ Flink 实时处理
Hudi（数据湖）
    ↓
HDFS（存储）+ Hive（查询）
```

### 核心功能

1. **CDC 数据同步**
   - 全量 + 增量同步
   - Schema 自动演进
   - 断点续传

2. **实时数据入湖**
   - 秒级延迟
   - ACID 事务
   - Upsert/Delete 支持

3. **流批一体查询**
   - Hive/Spark SQL
   - 增量查询
   - 时间旅行

### 性能优化

- Kafka 分区优化：256 分区
- Flink 并行度：128
- Checkpoint 间隔：5 分钟
- RocksDB 增量 Checkpoint

## 面试话术

### 如何介绍项目？

**STAR 法则**

- **Situation**：项目背景，解决什么问题
- **Task**：你的职责和任务
- **Action**：具体做了什么，用了什么技术
