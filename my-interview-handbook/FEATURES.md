#### 3. 术语提示系统 ✅
- 桌面端：点击显示提示卡片
- 移动端：点击弹出模态框
- 显示术语发音（拼音）
- 显示详细解释说明
- 美观的视觉效果（渐变背景、阴影等）
- 背景遮罩点击关闭

**示例术语**：

- 点击结果自动跳转
- 搜索结果高亮显示
- 清空按钮

#### 5. 响应式设计 ✅
- 桌面端：横向标签页导航

- 触摸友好的交互

### 🛠️ 后台管理系统

#### 6. 在线编辑器 ✅

- 文件列表侧边栏
- Markdown 编辑器（等宽字体）
- 实时未保存提示
- 保存成功/失败消息提示

#### 7. 自动备份系统 ✅
- 每次保存自动创建备份
- 备份文件命名：`filename.YYYY-MM-DD_HH-mm-ss.md`
- 备份存储在 `backups/人员名/` 目录
- 备份目录不提交到 Git（.gitignore）

#### 8. API Routes ✅
- `GET /api/people` - 获取人员列表
- `GET /api/content?person=xxx&file=xxx` - 读取内容
- `POST /api/content` - 保存内容（仅开发环境）
